# launch-scout-social

Публикации и автокомментарии Скаута AI (Launch Scout) в Threads, Instagram, X и TikTok.
Запуски — из Cloudflare Worker бота через `workflow_dispatch`; сбор данных и сам бот живут в закрытом репозитории.

Репозиторий публичный: логи прогонов видны всем. Куки и ключи — только в Secrets; скрипты не печатают
значения куки, тексты директа и HTML страниц, а скриншоты уходят владельцу в служебный бот, не в артефакты.
